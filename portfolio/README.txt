# 🎨 Styled Portfolio Website

## 📌 Overview

This project is a responsive portfolio website built by applying CSS styling to a basic HTML structure.

🔗 Project Reference: https://roadmap.sh/projects/portfolio-website

---

## 🚀 Features

* Responsive design (mobile + desktop)
* Navigation bar across all pages
* Multiple pages (Home, Projects, Articles, Contact)
* Clean layout using Flexbox
* Styled contact form

---

## 🛠️ Tech Used

* HTML
* CSS (Flexbox, Media Queries)
